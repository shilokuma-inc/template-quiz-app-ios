# 問題データの入稿ルール

外部委託で問題を作成してもらうときの入稿フォーマットです。委託先にはこのファイルと、
[Content/](../Content) のサンプル CSV（`categories.csv` / `questions.csv`）をそのまま渡してください。

## 全体の流れ

```
委託先: スプレッドシートで作成 → CSV で書き出して納品
  ↓
開発側: Content/ に置く → scripts/import-quiz.sh で検証・変換 → QuizTemplateApp/Resources/quiz.json
  ↓
CI:     CSV と quiz.json のずれ・問題データの誤りを検出
```

- 問題の原本は **CSV（`Content/`）** です。`quiz.json` は生成物なので手で編集しません
- Google スプレッドシート / Excel のどちらで作成しても構いません。1 シート = 1 ファイルで、1 行目を列名にします

## ファイル

### categories.csv（カテゴリ）

| 列名 | 必須 | 内容 | 例 |
|---|:-:|---|---|
| `id` | ✅ | カテゴリの ID。半角英数字・`-`・`_` のみ | `prefectures` |
| `name` | ✅ | カテゴリ名（画面に表示） | `都道府県` |
| `summary` | | カテゴリの説明（1 行程度） | `面積・県庁所在地など都道府県の基本` |
| `icon` | | アイコン（[SF Symbols](https://developer.apple.com/sf-symbols/) の名前）。空なら既定のアイコン | `map` |

- 行の順番がアプリでの表示順になります

### questions.csv（問題）

| 列名 | 必須 | 内容 | 例 |
|---|:-:|---|---|
| `id` | ✅ | 問題の ID。半角英数字・`-`・`_` のみ。**一度公開したら変更しない** | `prefectures-001` |
| `category_id` | ✅ | `categories.csv` の `id` | `prefectures` |
| `question` | ✅ | 問題文 | `日本で面積が最も大きい都道府県は？` |
| `choice_1` 〜 `choice_6` | ✅（1・2） | 選択肢。2〜6 個。`choice_1` から詰めて入力し、使わない列（末尾）は空にする。途中の列を空けるとエラー | `北海道` |
| `answer` | ✅ | 正解の選択肢の **番号**（1〜6） | `2` |
| `explanation` | | 解説（回答後と結果画面に表示） | `北海道は約 8.3 万 km² で…` |
| `image` | | 問題に添える画像名（開発側で Asset Catalog に登録したもの） | `hokkaido_map` |
| `fixed_order` | | `1` を入れると選択肢をシャッフルしない（「上記すべて」など順番に意味がある問題） | `1` |

- 選択肢はアプリで毎回シャッフルされるため、正解をどの位置に書いても構いません
- 列の順番は自由です。上記以外の列（`memo` など委託先の管理用の列）は無視されます
- 行の順番がカテゴリ内での並び順になります（出題時はシャッフルされます）

## ルール

- **文字コードは UTF-8** で保存してください（Excel の場合は「CSV UTF-8（コンマ区切り）」）。Shift_JIS も読み込めますが警告が出ます
- セルの中にカンマ・改行・`"` を含める場合は、セル全体を `"` で囲みます（スプレッドシートから書き出せば自動で囲まれます）
  - 例: `"富士山の標高は 3,776m です。"`
- `id` は成績（正解・不正解の記録）の保存キーになります。**問題文や選択肢を直しても `id` は変えない**でください。変えると、その問題の記録がリセットされます
- 同じ問題の中に同じ内容の選択肢を入れないでください
- 事実関係は出典を確認してください（納品時に出典を `memo` 列などに残してもらうと検品しやすくなります）

## 検証（開発側）

CSV を `Content/` に置いて、以下を実行します。

```bash
scripts/import-quiz.sh
```

誤りがあると、ファイル名と行番号つきでエラーが出て `quiz.json` は更新されません。

```
error: 問題 CSV の取り込みに失敗しました（1 件）
Content/questions.csv:10: 列の数がヘッダーより多くなっています。カンマを含むセルは "" で囲んでください
```

主なチェック内容:

- 必須の列・値があるか、`answer` が選択肢の番号として正しいか
- `id` の重複・使えない文字、存在しない `category_id`
- 選択肢の数（2〜6）、空の選択肢・重複した選択肢
- 列ずれ（カンマを含むセルのクォート漏れ）
- 問題が 1 問もないカテゴリ（警告）

CI でも `scripts/import-quiz.sh --check` が実行され、CSV と `quiz.json` が一致しない場合は失敗します。
また、アプリの Unit テスト（`QuizContentTests`）で、同梱した `quiz.json` の検証と、`image` に指定した画像が Asset Catalog にあるかを確認します。
